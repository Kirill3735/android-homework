Симулятор сервера

ФИО: Подгорных Кирилл Максимович

Группа: Б9124-02.03.01сцт

Приложение моделирует работу сервера с четырьмя состояниями (Остановлен, Работает, Перегрузка, Авария) и свойствами: имя, загрузка CPU, температура и версия ПО. Запустить сервер можно только из состояния Остановлен, если температура ниже 70 °C, а при подаче нагрузки показатели растут и переводят сервер в Перегрузку (от 70% CPU или 70 °C) или Аварию (при 100% CPU или 90 °C). Обновить версию ПО можно только в состоянии Работает, если одновременно загрузка CPU ≤ 60% и температура ≤ 65 °C, а охлаждение снижает нагрузку или выключает аварийный сервер.
