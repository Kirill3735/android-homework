# Симулятор сервера

ФИО: Подгорных Кирилл Максимовчи
Группа: Б9124-02.03.01сцт

Приложение моделирует работу одного сервера. У него есть имя, состояние
(«Остановлен», «Работает», «Перегрузка», «Авария»), загрузка CPU, температура
и версия ПО.

Правила:
- Запустить можно только остановленный сервер с температурой ниже 70 °C.
- Нагрузка повышает CPU и температуру. При 70 % CPU или 70 °C сервер
  перегружается, при 100 % CPU или 90 °C — аварийно останавливается.
- Охлаждение снижает нагрузку. После аварии сервер остаётся горячим (75 °C),
  и его нужно охладить, прежде чем запускать снова.
- Обновить ПО можно только в состоянии «Работает» при CPU не выше 60 % и
  температуре не выше 65 °C.
- Имя нельзя менять во время аварии.
- Сброс возвращает сервер в исходное состояние.

Экраны:
- Список серверов (12 штук при запуске). Состояние видно в строке, перегрузка и
  авария выделены цветом. Серверы можно добавлять и удалять.
- Экран сервера: все действия из первого задания. Изменения видны в списке.

Что изменилось в правилах:
- Сброс возвращает сервер в исходное состояние, имя при этом сохраняется.
- Новый сервер появляется в начале списка в исходном состоянии.
  
Задание 3. Работа с сетью

API: Open-Meteo (https://open-meteo.com), ключ не нужен.
Запрос: GET https://api.open-meteo.com/v1/forecast?latitude=..&longitude=..&current=temperature_2m

С сервера приходит текущая температура воздуха у дата-центра, где стоит
сервер. Она показывается на экране сервера. Если снаружи не теплее 5 °C,
действует свободное охлаждение: охлаждение снижает температуру на 30 °C
вместо 20 °C. Пока температура не получена, охлаждение обычное.

Загрузка, ошибка и «Повторить» показываются на экране сервера. При сбое сети
или ответе 5xx приложение само делает до 3 попыток с паузами 0,5 и 1 секунда.
Остальное управление сервером работает и без сети.

Как проверить:
- Откройте любой сервер: индикатор, затем температура снаружи.
- Режим полёта: через 1-2 секунды ошибка и «Повторить». Выключите режим
  полёта и нажмите «Повторить».
- Поворот экрана во время загрузки не создаёт второй запрос (Logcat, тег ServerHttp).
- Медленная сеть: флаг SIMULATE_SLOW_NETWORK в ServerApp.kt.
- Ошибка сервера: флаг SIMULATE_SERVER_ERROR в ServerApp.kt, в Logcat три запроса.
