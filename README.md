# Симулятор сервера

ФИО: Подгорных Кирилл Максимовчи
Группа: Б9124-02.03.01сцт

Приложение моделирует работу одного сервера. У него есть имя, состояние
(«Остановлен», «Работает», «Перегрузка», «Авария»), загрузка CPU, температура
и версия ПО.

Правила:
- Запустить можно только остановленный сервер с температурой ниже 70 °C.
- Нагрузка повышает CPU и температуру. При 70 % CPU или 70 °C сервер
  перегружается, при 100 % CPU или 90 °C — аварийно останавливается.
- Охлаждение снижает нагрузку. После аварии сервер остаётся горячим (75 °C),
  и его нужно охладить, прежде чем запускать снова.
- Обновить ПО можно только в состоянии «Работает» при CPU не выше 60 % и
  температуре не выше 65 °C.
- Имя нельзя менять во время аварии.
- Сброс возвращает сервер в исходное состояние.
